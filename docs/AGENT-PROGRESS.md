# Agent 处理状态卡

2026-10-15：按参考图增加“思考中”标记和当前步骤卡片。组件 AgentProgress 接受 key/title/description，同一张卡保持挂载，key 变化时旧文字向上退出、新文字自下向上进入；最终工具结果组件也向上滑入。减少动态效果设置会关闭旋转及位移动画。

progress.ts 根据本次请求的真实流状态选择步骤，不使用定时器编造任务进度。新工具默认使用通用核对提示并自动复用动画，可以按需登记更具体的标题。状态文字只描述业务进度，不展示模型内部推理内容。

处理中的纯查询状态、重复状态提示由统一进度卡承接；确认单、错误、风控拒绝仍正常展示。转账类步骤只说明准备确认、尚未执行，不代替银行验证。回答结束/取消后移除状态卡，原有停止与计划暂停逻辑保留。
