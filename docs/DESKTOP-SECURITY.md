# PC 安全验证窗口

PC（外层窗口至少 1024px）使用居中弹窗，最大宽度 940px；独立安全文档在至少 760px 的内部宽度下显示双栏。左侧为服务端提供的操作摘要，右侧为六格密码输入和所需身份验证，下方为取消及确认。

手机继续使用底部弹层、自定义数字键盘和原有验证交互。密码仍留在独立的同源文档中，父窗口仅接收尺寸与操作结果通知。

- 普通交易按服务端策略选择一种验证方式；界面不会强制额外增加因素。
- 双重验证展示密码与指纹／人脸；其他红色操作使用服务端允许的额外方式。
- PC 先选择方式，再点击“开始验证”。切换方式清除已完成的演示验证结果。
- 演示模式仅在服务端开启时可用，并明确说明不进行真实生物识别。
- 查看卡号、新卡密码设置、修改卡密码复用同一布局，并保留各自验证要求。

验证：类型检查、生产构建通过，卡片密码与权限相关 25 项回归测试通过。浏览器检查转账确认单进入双栏安全页、缺少密码时不可确认、演示验证加六位输入后按钮启用、切换方式后重新禁用，以及取消返回与手机键盘展开／收起。浏览器未点击最终确认，未执行转账。
