# Agent 手机键盘适配

- 打开 Agent 时由 Base UI 将焦点交给面板，不自动聚焦输入框；用户点击输入框才开始输入。
- 手机宽度或触控设备上，Agent 打开期间保存外壳尺寸。VisualViewport 变小时保持面板顶部位置，仅给对话区底部增加键盘遮挡距离，输入栏随之上移，消息区仍可独立滚动。
- 键盘显示时暂时隐藏输入栏下方的说明，输入栏距可视区域底部留 8px。收起后恢复说明和原有布局。
- iOS 可视区域平移通过 offsetTop 补偿；输入字号使用 16px，避免 Safari 聚焦时自动缩放。横竖屏切换重新测量，双指缩放不强制锁定布局。
- 行为仅在 Agent 打开时启用，关闭后清理监听、待执行帧和临时样式；银行卡独立安全页面不参与输入框处理。不支持 VisualViewport 的旧浏览器保留原生布局。

实现入口：`src/lib/agent-keyboard.ts`、`BankingHome.tsx`、`banking.css`。回归：`tests/agent-keyboard.test.ts`。

## 验证

已在隔离数据库的实际应用上，以 414×896 手机尺寸验证首次打开、关闭后重新打开均不聚焦输入框；手动点击输入后将可视高度缩至 550px，面板标题保持 y=40px，输入栏底边位于 y=541px。该步骤模拟键盘遮挡，不代表在真实 iOS/Android 软键盘上完成测试。

真机检查：打开 Agent 不弹键盘；点击输入框后标题保持原位、输入栏位于键盘上方，消息仍可滚动；收起键盘恢复全高；关闭并重开、横竖屏切换均可继续使用。
