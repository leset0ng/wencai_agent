# 桌面银行界面

2026-10-15：按两张桌面参考图重排现有银行功能。宽度达到1024px时采用左侧导航、中央账户余额与交易表、右侧安全提示/待确认转账/银行卡缩略图；较窄屏幕沿用原有手机布局。

- 黑夜模式使用近黑背景、深灰卡片、蓝紫色按钮与选中状态。白天模式沿用同样布局，使用浅色表面和蓝紫色强调色；主题仍优先遵循用户选择，未选择则跟随系统。
- 首页显示实际可用余额、总资产、最近六笔交易（高度不超过1000px的桌面窗口显示四笔）及对应银行卡/备注、月度收支。交易表随可用高度分配行间距，本月收支金额与图表适度放大，避免交易区底部大块留白。交易关联与备注由已有账单数据提供；没有添加账户币种划分或人民币筛选器。
- 待确认区只显示本人、未过期、未消费的转账类确认单摘要，不返回会话、参数、签名或私密字段。“查看并确认”打开原有银行确认卡，交易继续通过原有独立安全页面验证；取消使用原有确认接口。
- 银行卡缩略图显示现有卡片数量、备注与尾号，点击进入账户页并定位对应银行卡；完整卡号仍使用原来的安全验证流程。
- 账户页使用银行卡/账户信息/本月账单三栏，下方展示所选卡最近最多50笔交易。复用 AccountCarousel，换卡同步切换信息与账单。冻结、挂失放在账户信息底部，使用蓝灰/暗红描边样式；调整限额、冻结/解锁、挂失分别进入原有 CardServices 的专用表单，仍需核对和安全验证。信用卡保留还款、额度与账单日信息；手机界面沿用原布局。已用隔离库检查储蓄卡换卡空账单、信用卡额度入口、Agent 窗口并存与手机断点，无交易执行。
- Agent 继续使用可拖动悬浮入口。桌面点击后从右侧滑出非模态对话窗口，主页面和侧栏仍可使用；被覆盖的快捷信息隐藏并 inert。窗口支持展开/还原，关闭恢复右侧业务卡片。
- 同一个 ChatView 与 Sheet 在断点间保持挂载，避免旋转/改变窗口大小丢失聊天。手机上仍是可下拉收起的底部弹层，打开不自动聚焦输入框，保留键盘适配。
- 桌面对话使用四个现有业务快捷入口，没有添加附件上传或不存在的服务。动画复用 Motion、现有数字滚动、银行卡轮播和图表组件，尊重减少动态效果设置。

入口：`BankingHome.tsx`、`DesktopDashboard.tsx`、`desktop.css`、`Sheet.tsx`、`use-desktop-layout.ts`。`DashboardConfirmation.tsx` 复用原有确认卡和安全页面。

验证使用隔离库 `.scratch/desktop-preview.db`，创建待确认单但不执行转账。数据回归增加了待确认单的归属、有效期与私密字段排除检查；530项测试、类型检查与生产构建通过。截图和响应式检查记录保存在 `.scratch/desktop-*.png` / `.scratch/desktop-layout-proof.json`。
