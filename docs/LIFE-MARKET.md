# 生活商城与订阅管理

生活页使用现有 Base UI、Motion 和主题色。桌面宽屏显示两列横向商品卡片，窄屏自动调整为单列横向或手机双列卡片；Agent 仍使用现有浮窗。

- 商城：四件占位商品，支持搜索、详情和演示订单。订单按登录用户保存在当前浏览器，最多保留 50 条；不扣款、不发货，也不跨设备同步。
- 订阅：四项占位服务，支持搜索和方案详情。浏览方案不会开通服务或新增自动扣费。
- 我的订阅：读取本人银行数据中的已登记订阅，展示状态、月费与年费汇总，可搜索。取消订阅通过现有受控工具创建确认单，再进入核对和安全验证流程；不能直接修改状态或操作其他用户的订阅。
- 保留生日计划、AA 收款、任务中心和 Agent 订阅识别/续费提醒入口。
- 商品插画为本地 SVG，无外部图片请求。新增商品可复用 `LifeProduct` 数据、商品卡片和详情弹层。

验证：类型检查、生产构建和相关 33 项测试通过。测试覆盖目录搜索、演示订单解析及用户存储隔离、订阅取消确认单、未登录访问与跨用户权限隔离。浏览器在隔离演示数据库上检查搜索、商品详情、生成演示订单和取消确认单；未执行实际取消。
