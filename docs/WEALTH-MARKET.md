# 理财排行与指标

2026-10-22更新。偏好扩充与示例见 [FUND-CATALOG.md](FUND-CATALOG.md)。独立“理财”导航支持 PC 对比图和排行表、手机排行卡片、深浅色主题、自选、机构/风险/名称筛选。手动申购、订单和持仓保留在“我的理财”，确认及安全验证沿用原链路。

## 数据范围与来源

当前是白名单内21只公开基金的排行，其中8只债券型基金；“债券”分类显示债券型基金，不冒充独立银行债券或全市场榜单。数据与交易渠道分离，订单仍是模拟记账。

默认从天天基金/东方财富公开文本取得完整历史净值及公布日涨跌幅。只用正则提取固定赋值，再 JSON.parse，绝不执行下载的 JS。脚本端点失败时尝试东方财富 `https://api.fund.eastmoney.com/f10/lsjz` 最新20条，与离线完整历史合并；这两个接口属于同一生态，不是独立供应商。JSON兜底无法取得当前费率时暂停新申购，不阻止查询。网络全部失败保留有效缓存；空库从 `fixtures/funds` 初始化。请求、解析、校验均在数据库事务外完成。

原4只快照保留截至2026-10-20的净值，新增17只截至2026-10-21或22；21只基金均保留已取得的成立以来历史。启动时只给旧库补缺失历史与缺少的日收益字段，已完整的数据不重复重写，不覆盖已有价格、交易状态或当前费率。新增 metadata_json、daily_return_e8 和按用户隔离的自选表；升级不重置账户。机构、成立日期、规模等元数据取公开资料，规模注明报告日期，不能当实时规模。

来源：[天天基金公开数据](https://fund.eastmoney.com/data/)、[基金基本资料示例](https://fundf10.eastmoney.com/jbgk_110007.html)。接口无稳定性承诺，必须保留缓存、日期和来源提示。

## 指标口径

统一实现：`src/server/funds/analytics.ts`。页面、专家筛选和 Agent 使用相同算法。

| 项目 | 定义与限制 |
| --- | --- |
| 周期 | 日、周、月、三月、六月、一年、三年、五年、成立以来；月份按日历月向前截取，月末夹到目标月份最后一天 |
| 起点 | 日为相邻两条已公布净值；其他周期取不晚于目标日的最近观察，超过14天视为缺口；全周期必须覆盖实际成立日期附近 |
| 涨跌幅 | 优先用公布日收益率连接复利序列，避免除息时把分红误判成亏损；缺少日收益率时明确标注累计净值近似 |
| 夏普率 | 日超额收益均值 / 样本标准差 × √252；默认无风险年利率0%，不是平台官方夏普；至少20个收益样本 |
| 最大回撤 | 区间内复利序列相对历史前高的最大跌幅；内部以正数幅度保存，界面显示负号 |
| 年化波动率 | 日收益样本标准差 × √252；至少20个收益样本 |
| 年化收益率 | 区间复合收益按365.25日年化；少于90个自然日不展示 |
| 卡玛率 | 年化收益率 / 最大回撤幅度；零回撤不强行计算 |
| 缺失数据 | 显示“—”和原因，绝不置零；超过14日的历史间隔暂停夏普及年化统计 |

夏普定义参考[海富通基金说明](https://www.hftfund.com/contents/2024/5/21-fb18b9728dc54242bb1f84066852fe35.html)。这里的0%无风险假设及样本年化参数公开展示，因此数值可能与数据网站采用其他假设的夏普不同。日、周短窗口通常没有足够样本，不为每个窗口制造夏普率。

图表最多240点，降采样保留各桶极值及首尾。对比时在共同起点归一为100；指标仍按各自所选周期计算，不因图表对齐而改变。涨跌幅、夏普、最大回撤、波动率、年化收益支持升降序；空指标排末且不编号，金额并不参与业绩排名。

## Agent 与接口

- `rank_funds`：只读排行，支持周期、指标、升降序、机构、名称、风险、自选及assetClass/style偏好方向过滤。
- `get_fund_metrics`：只读返回单基金全部九周期、样本、区间、来源和计算说明。
- 自选星标通过已鉴权的显示偏好接口修改，无资金操作，按用户隔离且幂等；不向模型开放绿色写工具。Agent 可用 rank_funds 查询自选。
- 网页使用已鉴权 `/api/payments?view=wealth`（加 code 为单只详情），与工具共享服务 `funds/market.ts`。

Agent 不可把历史业绩说成预期收益、把债券基金说成银行存款，或用缺失指标补造排名。界面按钮向 Agent 发送完整的基金代码、周期和查询目的；咨询申购不等于授权。主对话的百分比核验范围保持原样，专家专用核验没有全局推广。
