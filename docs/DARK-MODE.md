# 银行黑夜模式

2026-10-14：按参考图采用深灰背景、分层灰色卡片、浅蓝强调色和白色主文字，保留原布局、滑动、上浮及图表动画。

入口：我的 → 安全与设备管理 → 外观设置。可选白天模式、黑夜模式、跟随系统；偏好保存在当前站点的 localStorage `theme`。未选择时跟随系统，存储不可用时仍可在当前页面切换。

- `src/lib/theme.ts` 统一解析、持久化、系统监听和跨标签同步。根文档的启动脚本在首屏样式和React初始化前设置实际主题，独立安全文档同样执行。
- `ThemeProvider` 覆盖主界面和独立安全页面；跨页面只同步主题偏好，不传递密码、验证码或交易验证信息。
- `dark-theme.css` 提供shadcn主题变量和银行组件适配，包括首页、账户、生活、Agent消息/图表/选择/确认卡、登录注册、设置、弹层、密码页、键盘及Base UI下拉门户。
- 新组件优先使用 `--background`、`--card`、`--foreground`、`--muted-foreground`、`--primary`、`--border` 等语义颜色，避免固定白底和深蓝文字。银行卡保留独立的蓝色/信用卡渐变，图表保留原动画及蓝色分类色板。
- 长账单的共享Reveal触发改为进入视口即可播放，避免高于数屏的列表永远达不到比例门槛而隐藏。

浏览器实测：在设置切换、刷新保留、账户账单、生活服务、真实Agent图表、密码页首屏，以及已打开主页面/独立iframe随另一标签的设置切换同步。测试使用 `.scratch/dark-theme-preview.db`，不输入卡密码、不执行转账。截图 `.scratch/dark-home.png`、`dark-accounts.png`、`dark-agent-chart.png`、`dark-settings.png`、`dark-security.png`；同步证明 `.scratch/dark-theme-sync.json`。

`tests/theme.test.ts` 验证首屏模式解析、系统跟随、独立文档背景、持久化、跨页同步、监听清理，以及存储不可用/写入失败的安全降级。

最终检查：当前工作区45个测试文件、502项通过（含9项主题专项），类型检查、生产构建及差异检查通过。原有交互模板和同工作区的HTTPS来源检查修改保留。
